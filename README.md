# Tiendas Mihon ES

Índices de extensiones en español para [Mihon](https://mihon.app), generados a
partir del índice de Keiyoushi.

Este repositorio solo aloja **archivos JSON**, ningún APK, y solo lista
extensiones que tengan al menos una fuente en español.

Hay cuatro listas para que elijas qué tan estricta quieres la tienda.

## Resumen

| Lista | Contenido | Extensiones | Archivo |
| --- | --- | --- | --- |
| Seguro | Solo `SAFE` | 47 | `safe.json` |
| Seguro + Mixto | `SAFE` y `MIXED` | 108 | `safe-mixed.json` |
| Mixto | Solo `MIXED` | 61 | `mixed.json` |
| Completo | Todo, incluido NSFW | 156 | `index.json` |

Cada archivo es una tienda independiente, con su propio nombre e insignia, así
que Mihon las muestra por separado.

## Listas

### 1. Seguro — `safe.json`

Solo extensiones marcadas `CONTENT_WARNING_SAFE`: sin contenido adulto ni
advertencias. Es la opción recomendada si hay niños usando el dispositivo.
47 extensiones.

Enlace para copiar:

```
https://raw.githubusercontent.com/ticolibre/Manga/main/safe.json
```

### 2. Seguro + Mixto — `safe-mixed.json`

Une las listas Seguro y Mixto: todo lo que no es NSFW. Incluye extensiones con
catálogos mixtos, donde puede aparecer contenido sugerente o adulto entre
títulos normales. 108 extensiones.

Enlace para copiar:

```
https://raw.githubusercontent.com/ticolibre/Manga/main/safe-mixed.json
```

### 3. Mixto — `mixed.json`

Solo extensiones marcadas `CONTENT_WARNING_MIXED`: catálogos que mezclan
contenido seguro con contenido adulto. No incluye las marcadas NSFW.
61 extensiones.

Enlace para copiar:

```
https://raw.githubusercontent.com/ticolibre/Manga/main/mixed.json
```

### 4. Completo — `index.json`

Todas las extensiones con fuente en español, incluidas las NSFW (contenido
explícito). 156 extensiones.

Enlace para copiar:

```
https://raw.githubusercontent.com/ticolibre/Manga/main/index.json
```
